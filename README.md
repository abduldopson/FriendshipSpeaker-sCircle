# Friendship Speaker’s Circle Website — Launch Candidate

This package is the polished launch candidate for Friendship Speaker’s Circle.

## Core Pages
- `index.html` — Home
- `about.html` — Mission, vision, values, identity, and member experience
- `start-here.html` — New-member roadmap
- `meetings.html` — Meeting flow, handoffs, timing, and Golden Rules
- `calendar.html` — 2026–2027 working club calendar
- `roles.html` — Meeting-role guides and resources
- `pathways.html` — Pathways, speech preparation, submission, and progress
- `mentorship.html` — Club, board, and Toastmasters mentoring system
- `member-hub.html` — Member dashboard and core actions
- `recognition.html` — Recognition system and Celebration Wall
- `leadership.html` — Executive committee and leadership standards
- `resources.html` — Organized resource library
- `join.html` — Guest / interest / joining page
- `officer-hub.html` — Protected leadership gateway
